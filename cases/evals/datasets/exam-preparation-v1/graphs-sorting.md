# 图、排序与算法选择讲义

广度优先搜索按层访问，在无权图上求最少边路径；深度优先搜索适合环检测、拓扑结构和连通性探索。邻接表遍历图的时间为 O(V+E)。拓扑排序仅适用于有向无环图。归并排序稳定、最坏 O(n log n)，需要额外线性空间；快速排序平均 O(n log n)、最坏 O(n²)，常具有良好局部性；堆排序最坏 O(n log n) 且原地，但通常不稳定。算法选择必须说明数据规模、稳定性、内存和输入分布。
