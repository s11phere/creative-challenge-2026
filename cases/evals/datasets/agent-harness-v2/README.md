# Dataset: agent-harness-v2

This is a body-free, synthetic, development-only fixture for the Agent Harness v2 contract. Each
case contains a category, expected state transitions, counters, and security assertions only. It
does not contain requests, prompts, answers, citations, document content, Tool payloads, provider
responses, secrets, or internal resource identifiers.

`formal_runs_enabled` is permanently false. Any semantic change requires a new dataset version and
new manifest hashes. This fixture is not a retrieval, answer, or Skill quality holdout.
