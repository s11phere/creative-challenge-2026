# Dataset: agent-loop-v1

This is a synthetic, development-only contract fixture for the generic Agent Loop. It covers
ordinary chat, repeated evidence gathering, insufficient or conflicting evidence, prompt injection,
cross-Space access, write approval, and command overreach.

The fixture contains no corpus text, personal content, credentials, provider responses, or formal
holdout cases. `formal_runs_enabled` is permanently false for this dataset version. Any semantic
change requires a new dataset version and new manifest hashes.
