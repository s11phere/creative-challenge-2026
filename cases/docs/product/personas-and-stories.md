# Personas & User Stories

> 对应计划阶段 0 产物

## Persona 1：学生

**背景**：正在学习 AI 和系统编程的通班同学，有大量课堂笔记、课程 PDF 和实验代码，需要高效检索和复习。

### 故事

1. **S1 - 成功导入并定位引用**
   Given 我有一份 CS229 的课程笔记和 AI 实验的 README
   When 我将它们导入知识库并提问"SVM 核技巧的核心思想是什么"
   Then 系统返回有依据的答案，引用可点击回到原文对应章节

2. **S2 - 跨文档回答**
   Given 我的知识库中有 CS229 的决策树笔记和 SVM 笔记
   When 我问"决策树和 SVM 处理非线性问题的方式有何不同"
   Then 系统综合两篇笔记给出对比，每项对比都有对应引用

3. **S3 - 无证据时拒答**
   Given 我的知识库中没有 Transformer 相关内容
   When 我问"Transformer 的自注意力机制是如何计算的"
   Then 系统回复"未在当前知识库中找到充分依据"而不是编造答案

4. **S4 - 引用失效**
   Given 我引用了一篇笔记中的内容
   When 该笔记被删除后
   Then 对应的引用应标注为来源已不存在，而不是返回失效链接

## Persona 2：科研人员

**背景**：阅读大量 ML/AI 资料，需要追踪概念的跨文档关联，在多个 PDF 之间快速定位证据。

### 故事

5. **S5 - 部分文档导入失败**
   Given 我尝试导入一批 PDF（包含损坏文件和正常文件）
   When 导入完成后
   Then 状态页面显示成功数和失败数，失败项标注原因，我可一键重试

6. **S6 - 文件修改、移动、删除**
   Given 我有一份已导入的操作系统笔记
   When 我修改了其中关于死锁的内容并再次导入
   Then 系统只重建修改影响的部分，不产生重复索引；回答引用可定位到更新后的版本

7. **S7 - 模型不可用**
   Given AI 服务接口暂时不可用
   When 我发起一个问题
   Then 系统给出清晰的服务降级提示，不把基础设施错误包装为"没有答案"

## Persona 3：开发者 / 自学者

**背景**：使用笔记系统整理 C++、操作系统、计算机网络的知识点，通过跨主题检索发现知识关联。

### 故事

8. **S8 - 空间隔离**
   Given 我同时有"ML 学习"和"C++ 系统编程"两个 Space
   When 在 C++ Space 中询问"SVM 原理"
   Then 系统不返回 ML Space 中的文档内容，而是提示未找到

9. **S9 - 增量更新**
   Given 我已导入一批笔记
   When 我修改其中一份笔记的文件名但内容未变化
   Then 系统保留原 Document 身份并更新规范化来源 URI；内容哈希未变化时复用已有解析与索引结果

10. **S10 - 回答反馈（P1）**
    Given 我收到了一个回答
    When 我认为回答不够准确
    Then 我可以提交反馈（赞/踩 + 可选文字说明），该反馈进入评测集候选列表
