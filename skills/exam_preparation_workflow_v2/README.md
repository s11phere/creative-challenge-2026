# exam_preparation_workflow 0.1.0

Provisional inactive manifest-v2 package. It freezes a resumable course-map, broad diagnostic,
adaptive follow-up, review-plan, approval-gated card preview, and mock-exam contract. Question papers
never contain answer keys. Answers and explanations appear only in a separate review result after
submission or explicit reveal. Past exams inform structure and difficulty, not verbatim reproduction.
